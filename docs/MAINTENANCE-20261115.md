# v0.3.0 代码修复与冗余清理（2026-11-15）

本维护版本保留 Alkove Focus → Denoiser DNS48 串联、推理参数、实时播放流程、固定窗口、2.6 秒自检动画、默认英文及语言保存行为。未引入第三方组件，版本仍为 0.3.0 / 0.3.0.0。

## 三项清理

- 删除未使用的 AdapterName 字段及相应显示属性查询；VB-CABLE 仍按真实硬件 ID 和服务识别。
- 删除未被调用的 Meter.DisplayDb 属性。
- 删除无人读取的 CaptureLatencyMs、RenderLatencyMs、关联变量和 GetStreamLatency 调用；保留 COM 接口方法位置。

未合并主输出与监听播放循环，未改模型清单维护方式，未删测试用途的模型单级入口或第三方上游代码。

## 六类修复

1. 安装状态文件：损坏、缺字段、不可读、锁定和读写/清理权限错误记录到日志，不阻断健康驱动。真实设备状态仍是判定依据。
2. 设备异常隔离：端点/PnP 逐项读取，单个失败不丢弃其余设备。默认设备和显示名称查询按可选信息处理；已识别的基础驱动硬件/服务/状态故障仍作为检测失败，不误称缺失。无法读取身份的设备不按显示名称认作 VB-CABLE。
3. 安装等待记录：安装前不写入成功待就绪记录；成功退出后写入 completed 标记。旧版未确认阶段记录先有限观察，再在安装器未运行且驱动仍缺失/不完整时允许一次修复；真正完成的待就绪记录继续防重复安装，明确重启要求保留。
4. 系统关闭：线程清理失败不再逸出事件处理器；取消本次可取消的关闭，恢复窗口/托盘和引擎引用供复位/退出重试。成功清理后才进入关闭状态；偏好保存异常单独记录。系统强制终止不受本程序控制。
5. 麦克风刷新：已选端点消失后保持未选择、停用启动并显示缺设备提示；重复刷新也不偷偷改选。用户明确选择另一个设备后正常保留选择。
6. 错误界面：真实错误提示可单击打开日志目录，普通提示无点击动作和悬浮框。固定窗口内微调提示/状态行分配，所有中英文错误建议可完整显示；通用建议不再在普通消息框内承诺可点击链接。
