# 界面与监听（v0.3.1）

## 主界面

主界面客户端为 480 × 456 逻辑像素，以 96 DPI 为设计基准，PerMonitorV2 下统一缩放，DPI 变化后重新布局并锁定外框尺寸。启动页为 480 × 280 逻辑像素。固定链路为 Alkove Focus → Denoiser DNS48；不提供模型开关、原声直通、声纹录入或增益滑块。

设备区从上到下为输入麦克风、虚拟输出、监听设备。输入与刷新按钮等高对齐；其后为输入/输出电平、监听/启动、提示和状态。页头提供语言切换。启动页为白底黑字 KeepClear 与蓝色光标，麦克风选择和动画规则见 [启动检查](STARTUP-INSTALL.md)。

背景 #F4F7FB，面板 #FFFFFF，正文 #182C3A，次要文字 #576C7C，蓝色 #1666C5，边线 #D6E0EA。使用 Microsoft YaHei UI：主界面品牌 20 pt，操作/设备文字 9 pt，提示 8 pt。

电平按 Stopwatch 实际时间推进 dB 域平滑，上升时间常数 25 ms、下降 240 ms，使用双缓冲绘制。窗口显示时轮询间隔 16 ms；隐藏后降为 250 ms 并暂停电平绘制，音频处理继续。

设备选择框的行高由 96-DPI 逻辑高度和字体容纳高度共同确定，在创建句柄、字体变化及父级 DPI 变化后重算。主界面刷新键跟随重算后的实际高度。托盘菜单使用独立的 9 pt 字体基准，弹出前后重新应用当前 DPI 的内边距，移除空图标/勾选边栏，并记录实际菜单 DPI、字号和条目大小。

## 设备选择与错误提示

- 四个设备选择框共用绘制规则：收起时白底黑字，展开后的悬停/选中行使用系统蓝底白字，禁用状态为灰色。
- 保留键盘选择，忽略鼠标滚轮切换，不绘制点状焦点框。
- 已确认的麦克风失效后保持未选择，刷新不自动换成其他麦克风；用户明确选择后才能启动。
- 普通文字不绑定悬浮提示，也不启用自动省略悬浮框。真实错误保留悬停详情和日志目录，并可单击打开日志。

## 监听

监听接收两级模型及输出增益/限幅后的同一份 PCM，使用独立 STA 线程、WASAPI 共享模式、重采样器和设备时钟。输入队列上限为 2048 个 16 kHz 样本，过载时丢弃最旧监听音频；监听故障不阻断主输出。

监听只能在处理已进入运行状态后开启。停止处理会停止监听，切换监听不重启模型，更换监听设备前需关闭监听。应用重启不会恢复监听开启状态；监听设备禁止选择 VB-CABLE。扬声器可能形成反馈，程序未实现声学回声消除。

## 语言与配置

无语言配置时默认英文。启动检查页和主界面共用 settings.xml，选择会保存，设备原名不翻译。语言切换不影响音频处理。旧 GainDb 继续读取，但界面不提供调整；旧模型开关节点在反序列化时忽略，下次保存不再写入。

固定窗口和托盘规则见 [TRAY.md](TRAY.md)，当前验证见 [VALIDATION.md](VALIDATION.md)。
