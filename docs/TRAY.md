# 固定窗口、单实例与托盘（0.3.4）

- 保留当前 480 × 456 逻辑像素的客户端尺寸。窗口首次显示、完成系统 DPI 缩放后锁定最小/最大外框尺寸，禁止拖动调整和最大化。此处固定的是当前逻辑布局；高 DPI 下 Windows 显示的实际像素数可能不同。
- GUI 使用 Windows 原生命名 Mutex 和 AutoReset 事件，同一用户、同一会话共用实例标识，与文件夹和版本号无关。第二个 GUI 进程发出激活事件后立即退出，不创建模型或打开音频设备；原窗口收到事件恢复显示。显式命令行自检/设备枚举不创建 GUI，不参与界面互斥。
- 点击关闭按钮或 Alt+F4 隐藏到托盘，不停止模型、麦克风、VB-CABLE 或已开启的监听。不在任务栏显示隐藏的窗口。
- 鼠标左键单击托盘图标，或重复启动程序，恢复原窗口和原音频引擎，不重复加载模型；已最小化的窗口也恢复正常显示。鼠标右键只打开菜单，不唤出窗口。托盘右键菜单仅保留“退出 / Exit”，随界面语言切换。
- 托盘菜单“退出”才释放音频设备、终止模型子进程、移除图标并结束程序。如启动/停止/监听切换正在进行，会记下退出请求，操作结束后执行。系统关闭/注销走退出清理流程，清理失败时保留可重试状态。
- 隐藏期间界面状态轮询降低到 250 ms，暂停电平绘制；音频线程和参数不变。恢复后回到 16 ms 界面刷新。
- 不新增登录启动项或后台服务。未启动降噪时关闭窗口只会保留空闲的托盘程序，不会自动采集麦克风。

当前托盘、单实例与关闭行为的测试范围见 [VALIDATION.md](VALIDATION.md)。
