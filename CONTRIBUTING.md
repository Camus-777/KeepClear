# Contributing

Read README, LICENSING.md and docs/BUILD.md before changing the project.
Original project contributions are shared under CC BY-NC 4.0; separately licensed
third-party content retains its own terms and attribution.

Keep changes scoped. Preserve the pinned model hashes and serial processing order
unless a model change is explicit. Run basic, UI and portable checks appropriate to
the change. Do not commit environments, runtime wheels, weights, local settings,
recordings, secrets, build output or private test logs. Use synthetic/reproducible
audio fixtures for tests and distinguish compute measurements from end-to-end latency.
